# Dunia Kerja, Proses Bisnis, Proyek, dan Mutu (`P1`)

## Target TKA

Mengidentifikasi profesi/tugas PPLG, menjelaskan peluang technopreneurship,
mengenali tahapan proyek, proses bisnis, HAKI, dan budaya mutu.

## Required Knowledge

- [Peta prasyarat PPLG](00-peta-prasyarat.md).
- Perbedaan kebutuhan pengguna, fitur, bug, dan kualitas.
- Komunikasi tim dan dokumentasi keputusan.

## Inti materi

Profesi dapat meliputi product/project manager, system/business analyst,
UI/UX designer, frontend/backend developer, database engineer, QA/tester,
DevOps, technical writer, dan game designer/programmer. Tugas tidak boleh
tertukar: UI/UX merancang pengalaman/tampilan; QA menguji; backend mengelola
logika/data server.

Proses bisnis umum: identifikasi masalah → analisis kebutuhan → desain →
implementasi → pengujian → rilis/deployment → pemeliharaan/evaluasi. Dalam
praktik iteratif, umpan balik dapat mengembalikan tim ke tahap sebelumnya.

Budaya mutu berarti kriteria selesai jelas, perubahan terlacak, code review,
pengujian dapat diulang, dokumentasi cukup, dan masalah dilaporkan tanpa
menyalahkan orang. HAKI meliputi hak cipta kode/aset, lisensi dependensi,
merek, dan izin penggunaan konten.

Technopreneurship dimulai dari masalah pengguna, proposisi nilai, target
pasar, model pendapatan, biaya, risiko, validasi MVP, dan kepatuhan lisensi.

## Contoh

Tim menemukan pengguna gagal menyelesaikan checkout. Analyst mengumpulkan
kebutuhan, UX membuat alur, developer mengimplementasikan, QA menyusun kasus
uji, lalu tim merilis bertahap sambil memantau error. “Langsung menambah
fitur baru” sebelum memahami masalah bukan proses mutu.

## Latihan

1. Tugas UI/UX → **merancang tampilan dan pengalaman pengguna**.
2. Bukti budaya mutu → **test case, code review, dan changelog yang dapat dilacak**.
3. Lisensi library harus → **dibaca dan dipatuhi sebelum distribusi**.
4. MVP → **versi minimum untuk memvalidasi nilai/masalah inti**.
5. Bug kritis setelah rilis → **catat, reproduksi, prioritaskan, perbaiki, uji regresi**.

## Checklist

- [ ] Membedakan profesi dan deliverable tiap peran.
- [ ] Menyusun urutan proses proyek.
- [ ] Menjelaskan mutu, HAKI, dan MVP dengan contoh.
