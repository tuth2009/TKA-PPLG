# K3LH, Budaya Kerja, Aset, dan Sistem Operasi (`P1`)

Halaman ini adalah indeks materi. Setiap topik memiliki satu berkas tersendiri:

1. [K3LH di lingkungan kerja PPLG](01-k3lh.md) — mengenali bahaya, menilai
   risiko, dan memilih pengendalian.
2. [Budaya kerja profesional](02-budaya-kerja.md) — disiplin, komunikasi,
   privasi, keamanan kredensial, dan penghormatan terhadap lisensi.
3. [Pengelolaan aset proyek](03-pengelolaan-aset.md) — mengenali aset fisik
   dan digital, menata, melindungi, serta mencadangkannya.
4. [Sistem operasi, berkas, dan direktori](04-sistem-operasi-file.md) —
   memahami path, file, folder, permission, dan operasi dasar secara aman.

## Required Knowledge

Tidak ada prasyarat khusus. Materi ini memperkenalkan praktik kerja dan
pengelolaan lingkungan proyek yang digunakan pada topik PPLG berikutnya.

## Tujuan umum

- Mengidentifikasi bahaya dan menerapkan pengendalian K3LH.
- Menunjukkan budaya kerja profesional dan menjaga informasi sensitif.
- Mengelola aset proyek dengan struktur, hak akses, dan backup yang sesuai.
- Menggunakan sistem operasi serta sistem berkas untuk menemukan dan mengelola
  file proyek dengan aman.

## Contoh struktur proyek

```text
project/
├─ src/          # source code
├─ tests/        # pengujian
├─ assets/       # gambar/audio dengan izin penggunaan yang jelas
├─ docs/         # kebutuhan dan keputusan
├─ .env.example  # nama variabel saja, tanpa secret
└─ README.md
```
