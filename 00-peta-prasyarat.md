# Peta Prasyarat PPLG (`P1`)

## Required Knowledge awal

Tidak ada. Materi ini memberi urutan agar istilah PPLG tidak dipelajari
terpisah-pisah.

## Empat kemampuan yang perlu dilatih

- **Konsep:** definisi proses bisnis, K3LH, jaringan, struktur program, OOP.
- **Penerapan:** gunakan konsep pada kasus pengembangan aplikasi/gim.
- **Analisis/evaluasi:** telusuri bug, bandingkan desain, nilai efektivitas.
- **Berpikir komputasional:** dekomposisi, pola, algoritma, abstraksi, data.

## Tes kilat

1. Dekomposisi berarti → **memecah masalah besar menjadi bagian yang dapat dikelola**.
2. Algoritma harus → **jelas, berurutan, dan berakhir**.
3. `return` pada fungsi → **mengirim hasil kembali ke pemanggil**.
4. Class adalah → **cetak biru; object adalah instansinya**.
5. HTTP berjalan pada konteks → **komunikasi aplikasi client-server melalui jaringan**.
